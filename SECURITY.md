# Security policy

Please report a vulnerability privately through GitHub Security Advisories for this repository. Do not open a public issue containing an exploit, credential, or private user data.

The router never executes or vendors upstream skills. Upstream references still influence agent behavior, so changes to repository ownership, license, install behavior, or pinned content should be treated like dependency changes. Sensitive routes must retain the security gate.

Before a public contribution, run `npm run check` and inspect staged files for credentials, local paths, conversation material, private URLs, and unrelated personal data.
