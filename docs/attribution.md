# Attribution model

The registry is the single source for generated credits. `CREDITS.md` groups human-friendly thanks by upstream project. `catalog/<skill-id>/README.md` gives every external capability its own author thank-you and provenance card. `THIRD_PARTY_SKILLS.md` lists each selectable capability and a pinned source.

This repository links to third-party work and does not redistribute its skill instructions. If vendoring is ever required, it needs a separate review of redistribution terms, copyright statements, notices, modifications, and license compatibility.
