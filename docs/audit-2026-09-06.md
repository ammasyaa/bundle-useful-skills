## Added searching stage

The new `search` command performs bounded evidence collection, native-shell-aware classification, reviewed registry matching, route generation, and an explicit selection/rejection report. It skips dependency/build/cache/VCS trees and does not expose environment or credential values. It is additive: explicit `route` and `report` commands remain supported.

## Remaining limitations

- Antigravity dormancy relies on the managed global rule and correct agent behavior; no equivalent per-capability explicit-only manifest is enforced by this project.
- SHA-256 inventories detect accidental drift but are not signatures against an attacker who can rewrite both installed files and metadata.
- The Windows symlink fixture can be skipped when the runner lacks permission to create symbolic links. Ubuntu and macOS CI exercise the non-following traversal path.
- Conditional tools such as delegated review or plan execution are reported as gaps when relevant; the bundle does not fabricate unavailable host capabilities.
- Full E2E depends on the reviewed upstream repositories remaining reachable.

## Release gate

Before merge or release, require `npm run ready`, `git diff --check`, the three-operating-system GitHub matrix, the dependent full E2E job, a focused diff review, and current generated attribution. The repository should be tagged or released only through a separate maintainer decision after those checks pass.
