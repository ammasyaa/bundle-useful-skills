# Model efficiency

Progressive disclosure has three levels: catalog metadata for discovery, one active `SKILL.md` when selected, and supporting references only when needed. The Agent Skills specification recommends this structure because the full instruction body enters context after activation.

A large installed inventory is useful for capability discovery. It is not a reason to activate everything. Cache stable project decisions such as platform, framework, backend, and approved design system, and reconsider them only when evidence changes.
