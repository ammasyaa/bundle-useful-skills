# Web Development Profile

The **Web Development** profile orchestrates full-stack web engineering, from Next.js and React architecture to backend systems, database modeling, SEO/GEO discoverability, and web performance.

---

## 2. Hard Constraints

- **Single Creative Director**: Never activate `taste-skill` and `anthropic-frontend-design` simultaneously.
- **Route Classification**: Classify routes as **Public Indexable** (optimized for SEO/GEO) or **Private/App** (protected behind auth, excluded from search indexing).
- **Evidence-Based Performance**: Never claim performance improvements from code inspection alone. Measure via DevTools traces, Lighthouse, or runtime synthetic profiling.
