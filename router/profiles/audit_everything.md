# Audit Everything Router Profile

## Overview
Coordinates rigorous, independent multi-perspective code and architecture audits.

## Primary Audit Trio
1. **Code Correctness & Quality**: `addy-code-review-and-quality` (or `compound-engineering-plugin` for large release gates).
2. **UI/UX & Platform Polish**: `pbakaus-impeccable` (visual hierarchy, typography, anti-slop, native feel).
3. **Security & Vulnerabilities**: `trailofbits-skills` + `owasp-secure-agent-playbook`.

## Optional Specialists
- **Database & Query Plans**: `supabase-postgres-best-practices`.
- **Web Quality & Accessibility**: `addy-web-quality-audit`.
- **Search & Schema**: `marketingskills-seo-audit`.

## Independent Audit Rule
The engineer or agent who implemented the code must not act as the sole auditor. Independent evaluation is mandatory before release.
