# Mobile Development Router Profile

## Overview
Routes mobile application tasks across Android, iOS, Flutter, and Expo / React Native.

## Supported Mobile Framework Authorities (Select Exactly One)
1. **Google Android**: `android-skills` (Jetpack Compose, Material Design 3)
2. **Apple iOS**: `openai-build-ios-apps` (SwiftUI, UIKit, Apple HIG)
3. **Flutter Mobile**: `flutter-agent-plugins` + `dart-lang-skills`
4. **Expo / React Native**: `expo-skills` + `emil-animate-expo`

## Non-Pollution Mandate
- Never mix iOS patterns into Android or vice-versa.
- Never apply web DOM/CSS styling models to Flutter or React Native.
- For cross-platform targets (Flutter and Expo), execute verification on both platforms before declaring task completion.
