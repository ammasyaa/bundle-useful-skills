# Desktop routing

Choose one lane: Flutter Desktop, WinUI, Tauri, Electron, or native macOS. Treat embedded React as renderer guidance inside Tauri/Electron. Validate resizable and minimum window sizes, keyboard/focus, shortcuts, pointing devices, dialogs, files, accessibility, packaging, signing, clean install, upgrade, and update behavior where applicable. For macOS releases, include notarization. WinUI metadata is pinned because its upstream skills describe themselves as preview.
